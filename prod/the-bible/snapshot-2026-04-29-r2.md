**Architecture State**

The current Gemma-4 E2B memory path remains a Layer 13 archival/query-capture system with Layer 14 KV_DIRECT attention steering. The important change since the deprecated snapshot is routing: the active route contract is now hybrid, not activation-only. TF-IDF/literal routing is retained for exact identity lookups, while Layer 13 mean-pooled activation routing handles semantic candidates when lexical evidence is absent.

The 100x100 random-marker suite is officially an exact/literal lookup benchmark. It is not a semantic-only activation benchmark because random hex keys collapse into a generic latent "hash/key" region. The semantic half now needs its own paraphrase test suite with near-zero literal overlap.

**3. Hybrid Retrieval And Routing**

`AsiRouterCandidate` now carries both lexical and activation evidence, including `raw_tfidf_score_pre_normalization`, `literal_score`, and `activation_score`: [asi_router.py](/mnt/c/Users/jehma/Desktop/lazarus/chuk-lazurus/src/chuk_lazarus/session_retrieval/asi_router.py:93).

The hybrid scoring contract is:

```text
if lexical_score > 0.0:
    lexical/literal evidence dominates the gate
elif activation_score >= LAZARUS_ASI_ACTIVATION_GATE_THRESHOLD:
    activation evidence passes as semantic routing
else:
    candidate does not pass by raw route score
```

`asi_route_candidates()` now scores TF-IDF/literal/entity rows for the candidate windows and overlays activation cosine scores when `activation_query_vector` is available: [asi_router.py](/mnt/c/Users/jehma/Desktop/lazarus/chuk-lazurus/src/chuk_lazarus/session_retrieval/asi_router.py:1011). **5. Semantic Test Gap**

The old activation-only random-marker attempt failed for the right reason: random hex identifiers do not represent semantic concepts. A target marker window can have a high activation cosine and still rank below unrelated marker windows because they share the same latent "hash/key" concept.

The semantic half should be validated with a separate small suite. Proposed fixture shape:

```text
memory window:
  "We painted the homepage hero cobalt blue after the launch review."

query:
  "What shade did we choose for the landing page header?"

expected:
  route_source = activation
  lexical_score ~= 0.0
  activation_score >= 0.45
  routed window contains the blue homepage fact
```

Include near-miss negatives, such as another window about the homepage layout or another color decision for a different page, to prove the activation gate is discriminating rather than topic-only.

Follow-up work is filed as `chuk-lazurus-v6i`: add a true semantic activation router test suite with paraphrase/no-shared-literal probes and negative controls.
